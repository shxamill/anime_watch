# Support

## Getting help

- Open a Bug report for a reproducible layout, interaction, or build problem.
- Open a Feature request for a focused improvement.
- For setup issues, include your Node.js and npm versions, operating system, command, and exact error.

Check the README and existing issues first. Include browser and viewport details for visual issues.

Do not post credentials, private information, or unredacted logs. For security issues, follow SECURITY.md. Support is provided on a best-effort basis.
